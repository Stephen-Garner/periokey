# Planning Required

Stephen's own list: things he has decided to look into more deeply himself, with an agent's help, before anything is built.

**A topic goes in only when Stephen says so** ("put this into planning-required"). Agents never add one on their own, not even when they think a topic needs research; they use `docs/awaiting-decisions.md` instead. Typical ways a topic arrives:

- From an ask: Stephen is asked to decide something and says he wants to look into it more first.
- From "To review": Stephen reads an agent's choice, is not happy with it, and wants to address it more deeply later.
- From his own ideas, when he names one for this list.

An agent may edit a topic or research it only when Stephen asks. A topic leaves this file only when Stephen decides it: then the head agent turns it into a roadmap slice in `docs/roadmap.md` (or drops it, if he says so). While a topic is here, no slice that depends on it starts.

Each topic says: the idea, the open questions, and the next step. Newest at the top.
